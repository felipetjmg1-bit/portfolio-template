# PORTFOLIO TEMPLATE · fluxo passo a passo

Modelo documental para apresentar projetos e evidências.

## 1. DEFINIR OBJETIVO

Identificar público, problema e finalidade do portfólio.

## 2. DESCREVER PROJETO

Registrar escopo, proposta de valor e arquitetura.

## 3. ANEXAR EVIDÊNCIAS

Adicionar links, imagens, testes e documentação verificável.

## 4. DECLARAR MATURIDADE

Separar conceito, demonstração, protótipo e produção.

## 5. PUBLICAR E REVISAR

Manter informações, autoria e links atualizados.

## Resultado e limites

Estrutura documental. O template não implementa uma aplicação de IA por si só.
